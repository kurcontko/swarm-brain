Connection

The console holds no privileges of its own. It reads the same authenticated routes every agent uses, with a token you issue. The token stays in this tab's session storage and is sent only as a bearer header.

Issue a read-only token whose run matches the run above:

SWARMBRAIN_TOKEN_SECRET=… uv run swarmbrain-token \ --tenant … --project … --repository … --swarm … \ --run <run id> --agent <any uuid> \ --capability events:read --capability metrics:read --capability memory:recall \ --ttl-seconds 3600

Those three capabilities are the whole grant: the token cannot claim a task, publish a memory, or read another run.
